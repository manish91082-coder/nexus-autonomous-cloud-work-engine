Admins can monitor usage, set limits and receive alerts; the native usage dashboard already provides visibility.

**Decision:** Do not build another static Jira Automation JSON analyser or a generic step-cost calculator. No such gap is yet proven.

## 4. Second product hypothesis: AI Business Automation Reviewer

This name is treated as a project/product hypothesis under the unified ₹10 Cr mission, not as proof that a market-ready product already exists.

### Buyer problem signals observed

- n8n's official `n8n audit` can report credential, database, filesystem, risky-node, custom/community-node and instance-security issues.
- Recent practitioner discussions describe retry classification, idempotency, duplicate side effects, webhook authentication, silent failure and recovery as production concerns.
- Public free tools and repositories already perform n8n workflow JSON static analysis, including secrets, open webhooks, retries, error handling, and production-readiness checks.
- A community post describes Auturance, a free static reviewer for n8n workflow exports. This means a basic upload-JSON-and-generate-report product is already commoditised.

### Product hypothesis to test, not yet approved

A cross-platform **Automation Reliability & Governance Control** product may have more defensible paid value if it can prove one or more of:
- Repeatable monitoring of workflow changes and runtime failures, not only one-time static file inspection.
- Evidence-backed replay/duplicate-side-effect protection and safe retry governance.
- Cross-platform inventory and controls across n8n, Power Automate, Make/Zapier or other supported systems.
- Continuous risk/coverage reporting with actionable evidence, change history and team governance.
- Private/local processing and data minimisation suitable for business workflow exports.

It must not claim runtime verification when it only analyses a static export. It must not upload workflow secrets or customer data without explicit user consent and security design.

**Current status:** RESEARCH_ONLY. Not selected for build or publication until competitor saturation, supported formats, user demand, and recurring paid value are verified.
