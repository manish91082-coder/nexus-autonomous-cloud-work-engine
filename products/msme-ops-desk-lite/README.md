# MSME Ops Desk Lite — Product Draft v0.1.0

## Positioning
An offline-first operational calculator and lightweight register for Indian micro and small businesses. It is a self-serve digital download, not a full ERP, accounting product, tax engine or consulting service.

## Included
- Unit contribution, contribution margin, break-even units and target-surplus calculator.
- Simple cash runway estimator.
- Inventory reorder-point planner using average daily usage, lead time and safety-stock days.
- Receivables register with balance and overdue-age display.
- Daily sales log with CSV export.
- Local JSON backup and restore.
- Local browser storage only; no external scripts, analytics, server or network calls.

## Design and safety
- No personal customer identity data should be entered; use internal references.
- No tax, legal, accounting or investment advice.
- All calculations are estimates and must be reconciled to source business records.
- Data remains in the current browser profile. Clearing browser data can erase it; export backups.
- No external dependency or subscription is required to run the HTML file.

## Validation status
- Private draft only. Not yet publicly published or offered for sale.
- Product-market fit is unproven. Channel-level digital product sales are not proof of demand for this specific toolkit.
- Need cross-browser testing, accessibility review, security review, formula tests, user testing and final owner approval before public release.
